PDFly REST API

One engine, every language. Use the same API from Python, PHP, Node.js, Ruby, C#/.NET, Java or curl.

1. List the tools

GET /api/tools # returns the full catalogue: id, title, category, accept, options

2. Upload files

POST /api/upload # multipart/form-data, field name: "files" (repeatable) # → { "ok": true, "job_id": "a1b2c3d4e5f6", "files": [ {"name":"a.pdf","size":1234,"ext":".pdf"} ] }

3. Process

POST /api/process # application/json { "job_id": "a1b2c3d4e5f6", "tool": "merge_pdf", # see /api/tools "options": { "level": "medium" } # optional } # → { "ok": true, "files": [ {"name":"merged.pdf","url":"/result/.../merged.pdf","size":123} ], "notes": [...] }

4. Download

GET /result/<job_id>/<filename> # single file GET /api/zip/<job_id> # ALL result files of a job as one .zip GET /api/preview/<job_id>/<file>?page=N # JPEG page preview (thumbnails) GET /api/pages/<job_id>/<file> # page count for the reader/annotator

5. Reorder (drag & drop order, no re-upload)

POST /api/reorder # application/json { "job_id": "a1b2c3d4e5f6", "order": [2, 0, 1] } # a permutation of the file indices

6. Status

GET /api/status/<job_id>

Examples in every language

Python

# pip install requests import requests base = "http://localhost:5000" with open("a.pdf", "rb") as f1, open("b.pdf", "rb") as f2: up = requests.post(base + "/api/upload", files=[("files", f1), ("files", f2)]).json() res = requests.post(base + "/api/process", json={"job_id": up["job_id"], "tool": "merge_pdf"}).json() for f in res["files"]: open(f["name"], "wb").write(requests.get(base + f["url"]).content)

PHP

<?php $base = 'http://localhost:5000'; $curl = curl_init($base . '/api/upload'); curl_setopt_array($curl, [ CURLOPT_RETURNTRANSFER => true, CURLOPT_POST => true, CURLOPT_POSTFIELDS => ['files' => new CURLFile('a.pdf'), 'files' => new CURLFile('b.pdf')], ]); $up = json_decode(curl_exec($curl), true); $curl2 = curl_init($base . '/api/process'); curl_setopt_array($curl2, [CURLOPT_RETURNTRANSFER => true, CURLOPT_POST => true, CURLOPT_HTTPHEADER => ['Content-Type: application/json'], CURLOPT_POSTFIELDS => json_encode(['job_id' => $up['job_id'], 'tool' => 'merge_pdf'])]); $res = json_decode(curl_exec($curl2), true); file_put_contents($res['files'][0]['name'], file_get_contents($base . $res['files'][0]['url']));

Node.js

// npm i form-data node-fetch const FormData = require('form-data'); const fs = require('fs'); const base = 'http://localhost:5000'; const fd = new FormData(); fd.append('files', fs.createReadStream('a.pdf')); fd.append('files', fs.createReadStream('b.pdf'); fetch(base + '/api/upload', { method: 'POST', body: fd }) .then(r => r.json()).then(async up => { const res = await fetch(base + '/api/process', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ job_id: up.job_id, tool: 'merge_pdf' }) }).then(r => r.json()); for (const f of res.files) { const buf = await fetch(base + f.url).then(r => r.buffer()); fs.writeFileSync(f.name, buf); } });

Ruby

# gem install httparty require 'httparty' base = 'http://localhost:5000' up = HTTParty.post(base + '/api/upload', body: { files: [File.open('a.pdf'), File.open('b.pdf')] }).parsed_response res = HTTParty.post(base + '/api/process', body: { job_id: up['job_id'], tool: 'merge_pdf' }.to_json, headers: { 'Content-Type' => 'application/json' }).parsed_response File.binwrite(res['files'][0]['name'], HTTParty.get(base + res['files'][0]['url']).body)
